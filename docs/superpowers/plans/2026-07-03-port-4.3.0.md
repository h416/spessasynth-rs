**Architecture:** 構造先行の二段階移植。フェーズ0で TS 4.3.0 リファレンス環境を整備、フェーズ1で Rust のファイル構成を 4.3.0 レイアウトに再編(挙動不変・出力完全一致を検証)、フェーズ2で 4.3.0 の挙動変更をファイル単位で移植する。スペック: `docs/superpowers/specs/2026-07-03-port-4.3.0-design.md`

**Tech Stack:** Rust (cargo)、TypeScript 参照実装 (`tmp/spessasynth_core-4.3.0`、tsx で実行)、比較ツール (`tools/batch_compare*.py|sh`、Python venv)

## 移植共通ルール(全タスク共通)

- 参照元: `tmp/spessasynth_core-4.3.0/src/`(新)、`tmp/spessasynth_core-4.2.0/src/`(旧)。各ファイルの移植内容は必ず次で確認する:
  ```bash
  diff -u tmp/spessasynth_core-4.2.0/src/<旧パス>.ts tmp/spessasynth_core-4.3.0/src/<新パス>.ts
  ```
- コメントは英語。`gen` は `r#gen`。`[f32]`/`Vec<f32>` 以外は f64 で計算し、配列代入時のみ `as f32`、取り出したら即 f64。MIDI チャンネルは 0 base。
- XMF(`midi/read/xmf.ts`)と SF3/Vorbis(`externals/stbvorbis_sync`、`basic_sample` の Vorbis 圧縮部)は移植しない。
- TS の `Math.random()` は移植しない。deterministic random(note_on の pan)は既存 Rust 実装のアルゴリズムを維持する。
- 各タスク完了時: `cargo build --release` が警告なしで通ること → コミット。

- [ ] **Step 1: 4.3.0 用比較スクリプトを作成**

`tools/batch_compare_430.sh`(既存 `batch_compare.sh` との差分は TS ソースパスと TS 出力先のみ):

```bash
#!/bin/bash
# Batch WAV comparison: TS 4.3.0 vs Rust
# Usage: bash tools/batch_compare_430.sh

set -e

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
PROJECT_DIR="$(cd "$SCRIPT_DIR/.." && pwd)"
cd "$PROJECT_DIR"

SOUNDFONT="sample/soundfont/GeneralUser-GS.sf2"
MIDI_DIR="sample/midi"
TS_DIR="sample/result/ts430"
RS_DIR="sample/result/rust"
TS_SRC="tmp/spessasynth_core-4.3.0"

MIDI_FILES=(
  Bond
  Breakout
  Dance
  EarthDay
  J-cycle
  Jump
  SantaClaus
  TheHYBRIDCollage
  UminoMieruMachi
)

mkdir -p "$TS_DIR" "$RS_DIR"

echo "=== Step 1: Generating TS 4.3.0 WAVs ==="
for name in "${MIDI_FILES[@]}"; do
  if [ -f "$TS_DIR/${name}.wav" ]; then
    echo "  SKIP: $TS_DIR/${name}.wav (already exists)"
  else
    echo "  Generating: $TS_DIR/${name}.wav"
    tsx "$TS_SRC/examples/midi_to_wav_node.ts" \
      "$SOUNDFONT" "$MIDI_DIR/${name}.mid" "$TS_DIR/${name}.wav"
  fi
done

echo ""
echo "=== Step 2: Generating Rust WAVs ==="
for name in "${MIDI_FILES[@]}"; do
  echo "  Generating: $RS_DIR/${name}.wav"
  cargo run --release --example midi_to_wav -- \
    "$SOUNDFONT" "$MIDI_DIR/${name}.mid" "$RS_DIR/${name}.wav"
done

echo ""
echo "=== Step 3: Comparing WAVs ==="
python3 "$SCRIPT_DIR/batch_compare_impl.py" "$TS_DIR" "$RS_DIR" "${MIDI_FILES[@]}"
```

Task 3 で実行方法が tsx 以外になった場合は Step 1 の生成コマンドをそれに合わせる。
